Common Client Problems

The problems I look for first.

Broken access, messy records, checkout mistakes, missing dashboards, mobile friction, and processes that depend too much on manual checking.

Broken login or onboarding

Fix auth-state problems, missing profile records, failed onboarding, and pages that break after login.

Messy database tables

Review table structure, relationships, foreign keys, naming, and whether the database matches the real process.

Unsafe access rules

Plan record access so buyers, sellers, staff, and admins only see or change the right information.

Inventory and checkout bugs

Improve stock checks, cart validation, order creation, seller grouping, and checkout failure handling.

Forms that do not save

Debug insert/update errors, validation gaps, wrong selectors, missing fields, and silent JavaScript failures.

Deployment and config issues

Check environment variables, Supabase links, local/cloud differences, CLI issues, and production cleanup.
